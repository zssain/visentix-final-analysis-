TYPOGRAPHY (3 FONTS, EACH WITH A JOB)
--------------------------------------------------------------------------------
- Fraunces (serif)   -> display headings, logo
- Inter              -> all UI, buttons, labels
- Source Sans 3      -> tabular numerics for scores/metrics
                        (.tabular, .stat-value, .score-num, [data-numeric])

Letter spacing:
  -0.02em          on large navy headings
  0.06em - 0.1em   on uppercase labels/tags

--------------------------------------------------------------------------------
NOTABLE UI PATTERNS
--------------------------------------------------------------------------------
- Sidebar nav: navy background, inactive links at 66% white opacity, active item
  gets a 3px teal left rail.
- Draft watermark: diagonal "DRAFT — PENDING EXPERT REVIEW" text at ~-30deg,
  gold at ~12% opacity.
- Login artwork pane: radial gradient of navy/teal/gold/exec-blue + SVG grain
  overlay.
- Form controls: focus outline 2px solid var(--exec-blue); hover border
  transitions to var(--teal); checkbox accent-color: var(--teal).
- Score/risk viz: navy-based shadows; risk ramp Low(green) -> Moderate(gold) ->
  High(red) -> Elevated(dark red); interactive score dial.
